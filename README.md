# 🪪 Crachá Digital - Flutter

Um aplicativo mobile simples desenvolvido em **Flutter** que simula um crachá de identificação corporativo. Este projeto é uma excelente referência de estudo sobre a construção de interfaces e a árvore de widgets do Flutter, contendo código detalhadamente comentado para facilitar o entendimento de cada componente.

## ✨ Funcionalidades

* **Identificação Visual:** Exibe um cartão estilizado com nome, cargo e setor do colaborador.
* **Layout Estruturado:** Utiliza componentes fundamentais de layout do Flutter (`Column`, `Row`, `Container`, `Padding`).
* **Interatividade Básica:** Um botão de ação (`FilledButton.icon`) que aciona um aviso (`SnackBar`) na parte inferior da tela confirmando a liberação de acesso.

## 🛠️ Tecnologias Utilizadas

* **[Flutter](https://flutter.dev/):** Framework UI do Google para criar aplicativos compilados nativamente.
* **Dart:** Linguagem de programação utilizada no projeto.
